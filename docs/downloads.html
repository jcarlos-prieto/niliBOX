niliBOX is now on version 1.2.0 which is a major relase with many new functionalities.

Here you can find the download for the different operating systems supported.

Windows
Compatible with Windows 10 (1809 or later) & 11 64 bits.

No installation needed! The installer is a zip file that you may unzip and place at any location in your computer. Just run the executable 'niliBOX.exe'.

Linux
Compatible with any Linux distribution using GLIBC 2.28 or higher.

Tested on CentOS Stream 8, Debian 11.6, Fedora 24, Mint 21, OpenSUSE 15.5, Red Hat 8.6, Ubuntu 22.04 and later versions of each distribution.

No installation needed! The installer is a tar.gz file that you may uncompress and place at any location in your computer. Make sure to run the script ./init.sh included in the distribution before running 'niliBOX'.

Available in 2 versions:
  • Standard: With graphical interface
  • Headless: Server mode. Accessible from another niliBOX on the same network
ARM Linux
Compatible with any Linux distribution for ARM 64 bit.

Tested on a Raspberry Pi 5 4GB running Raspberry Pi OS 64-bit (recommended), Raspberry Pi OS Lite 64-bit (no desktop), Ubuntu Desktop 25.10 64-bit and Ubuntu Server 25.10 64-bit.

No installation needed! The installer is a tar.gz file that you may uncompress and place at any location in your computer. Make sure to run the script ./init.sh included in the distribution before running 'niliBOX'.

Available in 2 versions:
  • Standard: With graphical interface
  • Headless: Server mode. Accessible from another niliBOX on the same network
macOS
Compatible with macOS 12 and later. Apple Silicon (arm architecture) supported

No installation needed! The installer is a dmg file which contains the niliBOX package. Copy it to any place on your Mac and run it.

Android
Compatible with Android 9 (API 28) and later.

Supports direct connection to USB devices, including USB serial ports.

It can be installed from Google Play or directly from the APK file provided.

iOS
Compatible with iOS 16 and later.

Does not support direct connection to USB devices. Recommended for remote control of other niliBOX installations.
